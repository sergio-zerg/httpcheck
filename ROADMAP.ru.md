# Роадмап

Статус: ✅ готово · 🚧 в работе · 🗓 запланировано · ❌ не планируется

Для своих задач утилита готова; запланированное ничего не блокирует.

## Готово

- ✅ Проверки HTTP(S) из YAML: код ответа, тип содержимого с разбором тела (text / json / xml / yaml), точное совпадение тела
- ✅ Два режима: файл → stdout для разработки, Consul KV → API результатов Sensu для продакшена
- ✅ Параллельные проверки, длительность запроса в каждом результате, таймаут на проверку
- ✅ Обновление 2.0.0: Go modules, свежие библиотеки, раскладка `internal/`, тесты, CI с линтером и govulncheck

## Запланировано

- 🗓 **Тело запроса и параметры** — POST с формой, JSON и XML через поле `params` (сейчас разбирается, но не используется)
- 🗓 **Повторы** — необязательное число повторов с паузой перед тем, как сообщить об ошибке
- 🗓 **Проверка адресов** — проверять адреса API Consul и Sensu при запуске в prod
- 🗓 **Индикаторы здоровья** — индикаторы статуса по каждой проверке, например в духе
  [docker-health-bridge](https://github.com/shurshun/docker-health-bridge)
- 🗓 **Раскладка cmd/** — если утилита разрастётся, перенести `main.go` в `cmd/httpcheck/`
